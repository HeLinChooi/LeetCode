# Archive: C++

These are solutions from before JavaScript became the interview language. They
are kept as a record. They are not maintained, and they are not part of the
current preparation plan.

Five of them were named `Day10.cpp` through `Day14.cpp`, which did not say what
they solved. They are now named `<problem number>-<Name>.cpp`:

| File | Problem |
|---|---|
| `104-MaximumDepthOfBinaryTree.cpp` | Maximum Depth of Binary Tree |
| `138-CopyListWithRandomPointer.cpp` | Copy List with Random Pointer |
| `207-CourseSchedule.cpp` | Course Schedule |
| `242-ValidAnagram.cpp` | Valid Anagram |
| `785-IsGraphBipartite.cpp` | Is Graph Bipartite? |
| `1091-ShortestPathInBinaryMatrix.cpp` | Shortest Path in Binary Matrix |
| `1342-NumberOfStepsToReduceToZero.cpp` | Number of Steps to Reduce a Number to Zero |
| `checkVersion.cpp` | Not a solution. A scratch file. |

Two compiled `.exe` binaries were tracked in git next to these files, 391KB in
total. They have been deleted, and `*.exe` is now in `.gitignore`.

Three of these problems appear in the current plan. Problem 138 was deliberately
removed from the linked-list section, because it depends on one memorable trick,
so solving it again would test memory rather than reasoning. Problem 242 is in
the calibration set, recorded as `messy`. Problem 207 is in the graphs section.
A C++ solution here is not a reason to skip any of them. The prep log explains
the rule.
